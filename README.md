# LED-Brightness-Control-Using-Potentiometer
This project controls LED brightness using a potentiometer. By rotating the potentiometer, the Arduino changes the PWM output, allowing the LED brightness to increase or decrease smoothly.
1. Aim
To create a simple adjustable LED lighting circuit that allows the user to control the intensity of an LED manually by changing the resistance of a potentiometer.
3. Problem Statement
A conventional LED circuit generally operates at a fixed brightness level. However, different situations may require different amounts of light. Changing components every time the required brightness changes is inconvenient. Hence, a simple user-controlled method is needed to adjust LED intensity easily.
4. Proposed Solution
The project uses a potentiometer as a manual control device for regulating the LED current. As the potentiometer knob is rotated, its resistance changes. This produces a corresponding change in the LED current and allows the user to obtain different brightness levels from the same LED.
5. Components Required
💡 Light-emitting diode for producing the required light output
🎚️ 10kΩ potentiometer for manual brightness adjustment
🛡️ 220Ω / 330Ω resistor for limiting LED current
🔲 Breadboard for assembling the circuit
🔋 9V battery as the power source
🔌 Battery connector for connecting the power supply
🔗 Jumper wires for completing the circuit
6. Circuit Working
The circuit converts the rotation of the potentiometer into a change in LED brightness.
When the potentiometer is adjusted to provide higher resistance, the current flowing through the LED decreases, resulting in lower light output.
When the resistance is reduced, the LED receives more current and produces greater brightness.
The fixed resistor is included to limit the current and help protect the LED. In this way, the potentiometer provides direct manual control over the light intensity.
7. Procedure
🔲 Prepare the breadboard and place the required components.
💡 Insert the LED with the correct polarity.
🛡️ Connect a 220Ω/330Ω resistor in series with the LED.
🎚️ Connect the potentiometer as a variable resistor.
🔗 Complete the circuit using jumper wires.
🔋 Connect the 9V battery through the battery connector.
🔍 Check the circuit connections and LED polarity.
⚡ Switch ON the power supply.
🎛️ Rotate the potentiometer gradually.
👀 Observe and compare the different LED brightness levels.
8. Applications
🌙 Adjustable lighting for different brightness requirements
🔆 Manual control of LED-based indicators
🖥️ Small display and signal-light experiments
🧪 Practical electronics laboratory demonstrations
🛠️ Beginner-level hardware prototyping
📚 Educational projects for understanding current control
9. Advantages
🎛️ Direct Control – Brightness can be changed instantly using the knob
💰 Budget Friendly – Uses simple and commonly available components
🔌 Easy Setup – Can be assembled easily on a breadboard
🧩 Simple Design – No programming or microcontroller is required
🔄 Variable Output – Different brightness levels can be obtained
🎓 Learning Oriented – Demonstrates resistance and current variation practically
10. Result
The LED brightness control circuit was successfully assembled and tested. Different levels of LED intensity were obtained by rotating the potentiometer. The experiment demonstrated that changing the resistance in the circuit can regulate the current through the LED and consequently change its brightness.
11. Conclusion
The project successfully demonstrates a simple method of controlling LED intensity through a potentiometer. The user can adjust the brightness manually without using software or complex electronic components. This project provides practical knowledge about variable resistance, current limitation, and LED operation and can serve as a basic model for adjustable lighting applications.
